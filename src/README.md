# Assignment 2 - DataStructures

## Description
Implementation of MyArrayList, MyLinkedList, MyStack, MyQueue, MyMinHeap in Java.

## Classes
- MyList - interface
- MyArrayList - array based list
- MyLinkedList - doubly linked list
- MyStack - based on MyLinkedList
- MyQueue - based on MyLinkedList
- MyMinHeap - based on MyArrayList
